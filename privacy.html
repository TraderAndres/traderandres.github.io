Privacy policy

Last updated: 4 November 2026

Media Factory is a private tool used only by its owner to manage his own YouTube channels. It is not offered to the public.

What it accesses

With the owner's permission through Google sign-in, it uses the YouTube Data API and YouTube Analytics API to read and update the owner's channel settings, playlists and videos, and to read the channel's analytics.

How data is used

Data is used only to run the owner's channels. It is not sold, shared with third parties, or used for advertising. Access tokens are stored privately and never published. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
